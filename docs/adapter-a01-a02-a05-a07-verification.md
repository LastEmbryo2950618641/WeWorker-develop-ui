## 网络与登录条件

- 用户已在专用浏览器完成 51job、携程和京东登录；没有保存密码、Cookie 或真实账号到仓库。
- 本机直连 Wikipedia 超时；使用系统已有代理后旧 REST 随机摘要接口返回 HTTP 429，官方 Action API 返回有效随机条目。本轮 Bridge 进程继承现有代理及 Node 环境代理开关，loopback 排除代理；没有修改系统代理、.env 或持久化客户端配置。重新启动 Bridge 时仍需保留可达 Wikipedia 的网络/代理环境。未复现截图中的具体旧重定向目标；新实现不再依赖该重定向链路。
- Wikipedia 保持 execution(type=api,runtime=background)、backend_fetch、browserFallback=false。验收只关闭任务自有页面。
- B 站自定义包的修复属于本机已安装包更新；仓库内置包已含正确主机范围。本轮没有发布、推送或覆盖自定义工具。
